## $\color{green}{\textsf{Antogeo}}$

**Data Analysis · Neuroimaging · Machine Learning**

Working at the intersection of neuroimaging, machine learning, and scientific programming, with detours through embedded systems, image processing, and the occasional medical-image pipeline that refuses to behave.

Familiar with running large-scale neuroimaging and ML analyses on **HPC** and **high-throughput computing (HTC)** clusters, using containerized pipelines.

Enjoying open science and sharing knowledge through teaching and supervising, a responsibility to society as much as a pleasure.
